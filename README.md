# Reservation System

A terminal-based reservation management system built in C++ to easily control and view reservations

## Features

* **View Reservations:** displays an organized table of all reservations and their details, as well as reservation queues for a specific resources
* **View Resources:** displays an organized table of all resources and their details
* **Search functions:** searches for reservation(s) or resource(s) using any criteria or multiple criterias
* **Add Reservation:** adds a reservation to the list of reservations and queues
* **Cancel Reservation:** removes all instances of the reservation and adds it to a stack of cancelations to be undone if needed
* **Clean Menus:** all tables and menus are well formatted with relevant clean headers

## Running the code

The code was built in C++ and compiled using MinGW. It runs on a Windows command prompt
<span style="color:red">**BUILD FOR WINDOWS**</span>

## Common Commands
Uses numbers in the console to control the program. All usable commands are shown in the menu
